    2: 
    3: ## 1. Identificación y Propósito del Proyecto
    4: * **Nombre de la Aplicación:** Biblia IDMJI (Iglesia de Dios Ministerial de Jesucristo Internacional).
    5: * **ID de Paquete Android:** `org.idmji.biblia`
    6: * **Directorio Base del Código:** `/home/rocua/Proyectos/IDMJI/Biblia_Android`
    7: * **Pipeline Backend y Compendio:** `/home/rocua/Proyectos/IDMJI/Compendio_Doctrinal_IDMJI`
    8: * **Objetivo:** Aplicación nativa Android moderna, rápida y 100% Offline-First para la lectura de la Biblia Reina-Valera 1960 (RVR1960), integrada de forma exclusiva e interactiva con el **Compendio Doctrinal IDMJI** (enseñanzas, estudios bíblicos, meditaciones y preguntas de la Hermana María Luisa Piraquive vinculadas versículo por versículo con marcas de tiempo a YouTube).
    9: 
   10: ---
   11: 
   12: ## 2. Stack Tecnológico y Arquitectura
   13: * **Plataforma:** Android Nativo.
   14: * **Lenguaje:** Kotlin 2.3+ (JVM Toolchain 17).
   15: * **Interfaz de Usuario (UI):** Jetpack Compose con Material 3 (`androidx.compose.material3`).
   16: * **Patrón de Arquitectura:** MVVM (Model - View - ViewModel) con programación reactiva mediante `StateFlow` y Corrutinas de Kotlin en `Dispatchers.IO`.
   17: * **Almacenamiento Local:** Base de datos relacional SQLite interna (`biblia_rvr1960.db`, versión 2), preempaquetada en `assets/` y copiada al almacenamiento interno del dispositivo con preservación automática de notas y marcadores de usuario.
   18: * **Paradigma de Conectividad:** **Offline-First**. Toda la lectura de la Biblia, el diccionario, las referencias cruzadas y las transcripciones completas del compendio funcionan sin conexión a internet. Solo se requiere conexión para reproducir el video en YouTube o para la sincronización automática de nuevos estudios.

   59: ## 4. Pipeline Backend y Modelo de Datos
   60: 
   61: ### Estructura de la Tabla SQLite `compendio_idmji`:
   62: ```sql
   63: CREATE TABLE compendio_idmji (
   64:     id INTEGER PRIMARY KEY AUTOINCREMENT,
   65:     tipo TEXT NOT NULL,                -- 'CANONICO' o 'TEMATICO'
   66:     libro_id INTEGER,                  -- ID del libro bíblico (1 a 66) o NULL si es temático
   67:     capitulo INTEGER,                  -- Capítulo bíblico o NULL
   68:     versiculo_inicio INTEGER,          -- Versículo inicial o NULL
   69:     versiculo_fin INTEGER,             -- Versículo final o NULL
   70:     cita TEXT,                         -- Ejemplo: 'Génesis 1:26', 'Mateo 9:22'
   71:     titulo TEXT NOT NULL,              -- Título del estudio o pregunta
   72:     video_url TEXT NOT NULL,           -- URL de YouTube con timestamp base
   73:     video_id TEXT NOT NULL,            -- Identificador de YouTube (ej. X3IFaTH0huk)
   74:     seccion TEXT NOT NULL,             -- Lista de origen (estudios_biblicos, meditaciones, preguntas_y_respuestas, transmisiones_en_vivo)
   75:     transcripcion TEXT NOT NULL        -- Transcripción completa con tags [[mm:ss]](url)
   76: );
   77: CREATE INDEX idx_compendio_verse ON compendio_idmji(libro_id, capitulo, versiculo_inicio, versiculo_fin);
   78: CREATE INDEX idx_compendio_tipo ON compendio_idmji(tipo);
   79: CREATE INDEX idx_compendio_libro ON compendio_idmji(libro_id);
   80: ```
   81: 
   82: ### Scripts de Extracción y Actualización en Python:
   83: * `actualizar_compendio_diario.py`: Monitorea las 4 listas oficiales de YouTube de la IDMJI, descarga subtítulos palabra por palabra (con estrategia híbrida Invidious + Tor SOCKS5 fallback ante límites de cuota) y detecta videos nuevos.
   84: * `actualizar_db_android.py`: Segmenta, identifica citas bíblicas mediante expresiones regulares y actualiza la base de datos `biblia_rvr1960.db` empaquetada en la app.

   88: ## 5. Optimizaciones Críticas Implementadas
   89: 
   90: 1. **Prevención de SQLite CursorWindow Overflow y ANR:**
   91:    - La base de datos contiene más de 80 MB de texto en transcripciones.
   92:    - Las consultas de listados y pestañas solo recuperan metadatos (`'' as transcripcion`); la transcripción completa se carga bajo demanda mediante `getCompendioItemDetail(id)` en milisegundos cuando el usuario abre el visor.
   93:    - Consultas temáticas con límite (`LIMIT 200`) y ejecución obligatoria en hilos de fondo (`Dispatchers.IO`).
   94:    - Se configuró `android:largeHeap="true"` en `AndroidManifest.xml` para garantizar headroom de memoria en dispositivos con recursos ajustados.
   95: 
   96: 2. **Independencia de Fuentes:**
   97:    - Las Referencias Cruzadas tradicionales y el Diccionario Bíblico son 100% independientes del Compendio IDMJI para preservar el rigor exegético y la claridad de la interfaz.
   98: 
   99: 3. **Soporte de Tiempos Extendidos:**
  100:    - Expresión regular adaptativa para soportar tanto formato `MM:SS` como `HH:MM:SS` (ej. `01:07:36`).
  101:

  104: ## 6. Siguiente Paso / Trabajo en Curso: Sincronización Automática Remota
  105: * **Reto:** Se publican nuevos videos y estudios bíblicos semanalmente. No se debe obligar al usuario a reinstalar la app ni a esperar aprobaciones de la Google Play Store para recibir las nuevas enseñanzas.
  106: * **Solución en Desarrollo:**
  107:   - **Backend (Nube):** Un cron o GitHub Action gratuito genera periódicamente un archivo liviano `version_compendio.json` y un delta de novedades (`compendio_novedades.json`, ~30 KB) alojado en GitHub Pages o CDN estática.
  108:   - **Cliente (Android):** Implementación de un WorkManager (`CompendioSyncWorker`) en segundo plano que consulta periódicamente (con Wi-Fi) el delta y hace `INSERT OR IGNORE` en la tabla local `compendio_idmji`.
  109:   - **Acción Manual:** Botón `🔄 Sincronizar enseñanzas` en la barra de la app para actualización instantánea a voluntad del usuario.

  540:     suspend fun parseAndResolveOfficialNote(noteText: String): List<ResolvedReference> = withContext(Dispatchers.IO) {
  541:         val list = mutableListOf<ResolvedReference>()
  542:         val db = readableDatabase
  543:         var currentBookId: Int? = null
  544: 
  545:         val parts = noteText.split(';').map { it.trim().trimEnd('.') }.filter { it.isNotEmpty() }
  546:         val bookRegex = Regex("""^((?:[1-3]\s+)?[a-zA-ZáéíóúÁÉÍÓÚñÑ]+)\.?\s*(.*)$""")
  547:         val cvRegex = Regex("""^(\d+)\.(\d+)(?:-(\d+))?""")
  548: 
  549:         for (part in parts) {
  550:             val bookMatch = bookRegex.find(part)
  551:             val rest = if (bookMatch != null && SBU_ABBR_MAP.containsKey(bookMatch.groupValues[1].lowercase())) {
  552:                 currentBookId = SBU_ABBR_MAP[bookMatch.groupValues[1].lowercase()]
  553:                 bookMatch.groupValues[2].trim()
  554:             } else {
  555:                 part
  556:             }
  557: 
  558:             val bId = currentBookId ?: continue
  559:             val bName = getBookName(bId)
  560: 
  561:             val cvMatch = cvRegex.find(rest)
  562:             if (cvMatch != null) {
  563:                 val chapter = cvMatch.groupValues[1].toIntOrNull() ?: continue
  564:                 val vStart = cvMatch.groupValues[2].toIntOrNull() ?: continue
  565:                 val vEnd = cvMatch.groupValues[3].toIntOrNull() ?: vStart
  566:                 val text = resolvePassageText(db, bId, chapter, vStart, vEnd)
  567:                 val citation = if (vStart == vEnd) "$bName $chapter:$vStart" else "$bName $chapter:$vStart-$vEnd"
  568:                 list.add(
  569:                     ResolvedReference(
  570:                         citation = citation,
  571:                         bookId = bId,
  572:                         bookName = bName,
  573:                         chapter = chapter,
  574:                         verseStart = vStart,
  575:                         verseEnd = vEnd,
  576:                         text = text
  577:                     )
  578:                 )
  579:             }
  580:         }
  581:         list
  582:     }

  592:     fun resolvePassageText(db: SQLiteDatabase, bookId: Int, chapter: Int, startVerse: Int, endVerse: Int): String {
  593:         val cursor = db.rawQuery(
  594:             "SELECT versiculo, texto FROM versiculos WHERE libro_id = ? AND capitulo = ? AND versiculo >= ? AND versiculo <= ? ORDER BY versiculo",
  595:             arrayOf(bookId.toString(), chapter.toString(), startVerse.toString(), endVerse.toString())
  596:         )
  597:         val sb = StringBuilder()
  598:         cursor.use {
  599:             while (it.moveToNext()) {
  600:                 val vNum = it.getInt(0)
  601:                 val text = it.getString(1)
  602:                 if (startVerse == endVerse) {
  603:                     sb.append(text)
  604:                 } else {
  605:                     if (sb.isNotEmpty()) sb.append(" ")
  606:                     sb.append("[$vNum] $text")
  607:                 }
  608:             }
  609:         }
  610:         return sb.toString().trim()
  611:     }
